# Scratch 檔案分析師

這是一個 Codex skill。將 Scratch 3 原始檔（`.sb3`）交給 Codex，可取得完整腳本索引、繁體中文 Scratch 3 積木圖、來源對照，以及可離線瀏覽的作品分析和思考挑戰。

## 開始使用

1. 下載或複製這個儲存庫，並用 Codex 開啟資料夾。
2. 依[安裝說明](.agents/skills/scratch-analyzer/README.md)備妥 Python、Node.js、Chrome 與渲染套件。
3. 附上原始檔並輸入「用 `$scratch-analyzer` 分析這個 Scratch 專案」。

這裡只收錄一個案例：[旋轉出美麗的花朵](.agents/skills/scratch-analyzer/assets/example/index.html)。下載後用本機瀏覽器開啟案例的 `index.html`，即可離線閱讀。若要把 skill 加到別的工作區，請依安裝說明複製完整的技能資料夾。
