## 驗證範圍

- **文字與 SVG**　依來源 `next`、`SUBSTACK`、輸入及 EFFECT 欄位核對積木順序、巢狀結構和數值。核對兩張圖的繁體中文標籤、顏色選單與 Scratch 3 樣式，並以 Chrome 頁面截圖目視檢查完整圖與細部圖。
- **離線網頁**　用 Chrome 直接開啟本機頁面，檢查 1280px 與 390px 版面、素材顯示、所有詳情和返回連結、挑戰的三個積木連結，以及未選答案提示、三種選項回饋及重作。在 280px 確認兩張積木圖均可各自水平捲動。[瀏覽器驗證紀錄](browser-validation.json)
- **原作下載**　首頁下載連結指向雜湊相符的 `original.sb3`。自動化 Chrome 觸發下載後回報取消，下載另存未驗收。可直接從交付資料夾複製原檔。
- **原作執行**　在本機 Scratch VM 15.3.0 與 Scratch Render 以一般速度連續點兩次綠旗，每次先清除再蓋章 250 次。核對每次蓋章的方向、顏色值、位置與 Broom 造型。第一枚尺寸約為 508%，最後一枚約為 11.42%。兩輪的第一枚方向分別為 −5° 與 −65°。第二輪開始時顏色已重設，方向承接第一輪結束時的 −95°。[執行紀錄](runtime-validation.json)
- 既有的 18 項轉換與教材測試通過。網頁檢查限本機 Chrome，Scratch 執行檢查限上述 VM 版本與綠旗流程。自由改造的 45° 情境留作課堂活動，原檔保留 30°。
