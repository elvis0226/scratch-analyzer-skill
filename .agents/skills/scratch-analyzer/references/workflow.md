# 分析與交付規格

## 從原檔盤點

- 依 `isStage` 區分舞台與角色。統計廣播時按 ID 去重。變數及清單保留作用域，自訂積木按角色及定義計數。造型、背景和音效依原始順序列出，縮圖優先使用目前的造型或背景。
- 保留沒有腳本的角色及舞台，詳情顯示「無程式積木」。原始素材缺少時保留名稱並顯示占位。
- 由 `next` 和 `inputs` 追蹤語意，留意廣播是否等待、分身與本體、全域與角色變數、選單及巢狀分支。完整腳本及細部各記錄實際涵蓋的 block ID。為獨立運算式增加外框或改寫教學示例時，標示「教學示意」並記錄改動。
- 未知 opcode、缺失或循環的引用、選單翻譯問題和渲染失敗都要記錄到對應腳本。保留角色、事件、頂層 block ID、可取得的出錯 block ID、opcode 與原因。有已核對的 TXT 時仍交付，並於頁面顯示 SVG 狀態。

## 運算思維標籤

每種標籤在總覽只列一次，在 `check/` 留存角色或舞台、頂層 block ID、證據 block ID 及判定理由。選用有實際程式證據的項目。

| 標籤 | 判定依據 |
| --- | --- |
| 循序 | 可指出執行先後如何影響結果。 |
| 變數 | 讀取、設定或更新變數。 |
| 清單／陣列 | 讀取或修改清單。 |
| 迴圈 | 使用重複、持續重複或重複直到。 |
| 事件處理 | 點擊綠旗、接收廣播等事件觸發腳本。 |
| 布林邏輯 | 有比較、且、或、不等回傳真假的積木。 |
| 條件判斷 | 有以條件控制的分支。 |
| 隨機 | 隨機值或選項影響結果。 |
| 協調與同步 | 可指出腳本協作或等待關係。 |
| 平行執行／執行緒 | 多條腳本可在同一時間段執行。 |
| 分身 | 有建立分身及可追溯的分身行為。 |
| 參數 | 自訂積木接收呼叫者傳入的參數。 |
| 程序 | 有自訂積木定義與呼叫。 |
| 實體感測 | 讀取麥克風音量或視訊動作等實體輸入訊號。 |

## 離線網頁

所有頁面使用「SCRATCH ANALYZER」頁首及相對路徑。輸出文字須做 HTML 跳脫。用獨立且穩定的識別碼當檔名與積木錨點。素材 SVG 作為圖片載入。手機版依閱讀順序重排，過寬的積木圖在自身容器內水平捲動。

| 頁面 | 內容 |
| --- | --- |
| 作品總覽 `index.html` | 作品名及原檔下載、擴充功能、運算思維標籤。下一區為廣播、變數／清單及自訂積木的名稱與數量。下方是角色、舞台的縮圖及詳情連結，另有思考挑戰入口。 |
| 角色／舞台詳情 | 有「回總覽」。上方依序列出從 1 起算的造型或背景縮圖與名稱，旁列音效、角色或全域變數與清單。下方逐支顯示事件、完整圖或受阻狀態。重點腳本同區放程式解說、細部圖與說明。 |
| 思考挑戰 `challenge.html` | 有「回總覽」。依序為常見卡點、自由改造與檢查理解，並連至相關積木錨點。從可觀察現象帶到原作行為，改造題引導先預測再比較，選擇題提供具理由的回饋並可重新作答。 |

空欄顯示「無」。以離線瀏覽器從本機開啟，點遍角色／舞台、回總覽、挑戰入口及積木錨點。檢查所有答題路徑、下載連結及原檔雜湊、約 390px 的重排與過寬圖的局部捲動。若瀏覽器阻擋另存，分開記錄連結、檔案雜湊與實際下載結果。

## 來源與驗證紀錄

將原始 SB3 與成品頁一起交付。`check/` 收錄 UTF-8 TXT、稽核、來源對照、運算思維證據及受阻清單。來源對照至少包含原檔 SHA-256、角色／舞台、事件或頂層 opcode、頂層及涵蓋的 block ID、TXT／SVG 路徑與檢查結果。實際在 Scratch 或 Scratch VM 執行時，才記錄操作、版本與觀察結果。
